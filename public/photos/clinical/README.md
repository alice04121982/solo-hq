# Clinical photography

Licensed iStock imagery of the clinical side of treatment: labs, embryology,
medication, consultations. Family and story photography lives one level up
in `public/photos/`.

- Name files `istock-<id>-<short-slug>.webp` (e.g.
  `istock-2258278158-icsi-procedure.webp`) so every file traces back to its
  licence.
- Every file in here must have a row in `docs/stock-imagery.md` — that file
  is the licence record and explains the purchase and the sensitive-use
  disclaimer.
